# Lattice-Physics Regression

Terms used to describe the fuel-assembly simulation data and its prediction
outputs.

## Language

**Fuel-pin enrichment**:
The weight percentage of U-235 in a fuel pin. Each dataset instance describes
39 enrichment values for one-eighth symmetry of a fuel assembly.

**k-inf**:
The infinite multiplication factor produced by the lattice-physics simulation.
It is a continuous output.

**PPPF**:
The pin power peaking factor produced by the lattice-physics simulation. It is
a continuous output distinct from k-inf.
