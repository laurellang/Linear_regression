# 线性回归实验结果

所有模型使用相同的数据划分：训练集 19,200 条，验证集 4,800 条，随机种子为 42。手写模型学习率为 0.01，迭代 2000 次。

## 1. 模型性能对比

| 模型                 | L2 强度 |  训练 RMSE |   验证 MAE |  验证 RMSE |    验证 R² |
| -------------------- | ------: | ---------: | ---------: | ---------: | ---------: |
| 手写普通线性回归     |       0 | 0.00204770 | 0.00155124 | 0.00203808 | 0.98682145 |
| sklearn 普通线性回归 |      无 | 0.00204770 | 0.00155124 | 0.00203808 | 0.98682145 |
| 手写 L2 线性回归     |     100 | 0.00204977 | 0.00154824 | 0.00203661 | 0.98684052 |

## 2. 正则化参数比较

| L2 强度 |       验证 MAE |      验证 RMSE |        验证 R² |
| ------: | -------------: | -------------: | -------------: |
|       0 |     0.00155124 |     0.00203808 |     0.98682145 |
|       1 |     0.00155120 |     0.00203805 |     0.98682192 |
|      10 |     0.00155082 |     0.00203774 |     0.98682583 |
| **100** | **0.00154824** | **0.00203661** | **0.98684052** |
|    1000 |     0.00163926 |     0.00218990 |     0.98478497 |

## 3. 结果说明

- 手写普通线性回归与 sklearn 的验证预测平均绝对差约为 $2.5\times10^{-9}$，结果基本一致。
- 按验证 RMSE 最小选择 L2 强度 100，相比基础方案，验证 RMSE 降低约 0.0724%，改善有限。
- L2 强度增大到 1000 时性能下降，说明正则化并非越强越好。
- 以上为固定验证集结果，验证集参与参数选择，独立测试集尚未评估。
