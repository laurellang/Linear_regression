# Domain docs

This repository has one domain context. Before exploring or modifying a
concept, read the root `GLOSSARY.md` and relevant records in `docs/adr/` if
they exist. Create them only when a term or durable decision is resolved.

Use glossary terms consistently in issue titles, tests, code discussions, and
review findings. If a proposed change conflicts with an ADR, name the ADR and
explain why the decision should be revisited.
